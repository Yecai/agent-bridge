## 边界

- 不为验收重启用户 VPS；断线、进程强杀和租约测试不能称为真实操作系统重启验收。
- 全权 shell 是本机用户权限，文件根限制不构成 OS 沙箱；故意 setsid 脱离进程组的程序没有完整隔离保证。
- 未知界面或新 API key 的原生确认可能需要初始化终端；受控目录确认只匹配已验证的启动界面与本工具私有空目录。
- grep 目前收集 rg 输出后分页，超大查询应缩小范围。未知业务秘密不能保证自动识别。
- 测试默认不访问真实 VPS。测试 SSH、fake Claude、真实上游模型、真实浏览器的证据分别记录。
